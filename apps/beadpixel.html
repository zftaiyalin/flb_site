关于 BeadPixel

BeadPixel 是一款面向拼豆、像素手作与图案设计的工具。你可以导入喜欢的图片，将其转换成清晰的像素网格，按颜色统计用量，并跟随图纸逐格完成作品。

核心功能

  • 图片转像素拼豆图纸
  • 可调整画布尺寸、像素密度与颜色数量
  • 自动生成颜色编号和用量统计
  • 支持网格预览，方便逐行对照制作
  • 保存项目进度，随时继续编辑
  • 无广告，无追踪

About BeadPixel

BeadPixel is a tool for fuse bead art, pixel crafts, and pattern design. Import an image, convert it into a clear pixel grid, review color counts, and follow the pattern cell by cell as you build.

Key Features

  • Convert images into pixel bead patterns
  • Adjust canvas size, pixel density, and color count
  • Generate color labels and bead quantity summaries
  • Grid preview for row-by-row crafting
  • Save project progress and continue editing anytime
  • No ads, no tracking
